Overview
========

The `scripts` area should be used to hold common scripts that are reusable across multiple platforms and/or experiments.

Configuration Scripts
---------------------

The `scripts/configuration` directory is meant for scripts that generate or process configuration files for specific software (e.g., benchmark configuration files).

Experiment Scripts
---------------------

The `scripts/experiment` directory is meant for scripts that provide common functionality for running experiments and tests on the various client and server platforms.

Installation Scripts
---------------------

The `scripts/installation` directory is meant for scripts that are used to install benchmarks and applications on the various client and server platforms.
