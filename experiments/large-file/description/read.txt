Test Description
================

This test evaluates the dataset analysis performance of the 'large-file'
experiment. The test simulates the actions of a collection of uncoordinated
parallel processes that read random batches of segments from the shared file
dataset in each analysis iteration. 

Test Configuration
==================

This test uses the elbencho benchmark in parallel to independently perform the
random read iterations. Over the course of multiple iterations, the entire
shared file contents are read multiple times, but there is no temporal or
spatial locality for reads from a given client.

The associated ior configuration file is:
read/scripts/config/dataset_read_large_file.elbencho.cfg
