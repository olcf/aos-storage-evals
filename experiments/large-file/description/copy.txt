Test Description
================

This test evaluates the dataset copy performance for the 'large-file'
experiment. The test simulates the actions of a collection of coordinated
parallel processes that read segments of the shared file from a source
storage system and write them to a copy of the dataset on the target
storage system.

Test Configuration
==================

This test utilizes the mpiFileUtils dcp utility to copy the dataset using
N parallel processes, with each process responsible for 1/N of the file's
data and issuing large sequential I/O operations.

The associated dcp configuration file is:
copy/scripts/config/dataset_copy_large_file.mfu-dcp.cfg
